# eization

Practice for any instrument. One example at a time, with the metronome. The practice screen is one static page. Guide pages sit beside it. No build step, no backend. It runs from `file://` and from GitHub Pages.

## Run

Open `index.html`, or serve this folder as the site root. Asset paths are relative (`./resources/...`).

## Publish

GitHub Pages, branch of your choice, folder `/` (the repo root). Keep `.nojekyll` so Pages does not drop files that start with `_`.

The public address used for search and link previews is `https://eization.com/`. `CNAME` keeps that host on GitHub Pages. If that address changes, update these together:

- the canonical link, Open Graph URL, and image URLs in `index.html`, `practice.html`, the book pages, the teacher pages under `for-teachers/`, and each exercise page
- `robots.txt`
- `sitemap.xml`
- `CNAME`

After a publish, submit `sitemap.xml` in Google Search Console for that host.

## Staff notation (optional)

An example line that parses as music notation renders as an SVG staff instead of HTML text. A trailing ` · ` caption (or HTML `prog-changes` / `prog-name`) is stripped before parse and shown under the staff. The music side still rejects `<` or `&`. Notation-ish lines that fail to parse fall back to HTML text and log a `console.warn`.

- Clef / key: leading `@treble` or `@bass` and `@key=NAME` in any order (default treble, key C). Unknown `@…` tokens are rejected. Clefs and keys alone (no notes) still draw an empty staff
- Key names: major (`@key=G`, `@key=Eb`, `@key=F#`) or minor aliases that map to the relative major for the signature only:

  | Alias | Signature | Alias | Signature |
  | --- | --- | --- | --- |
  | Am | C | Dm | F |
  | Em | G | Gm | Bb |
  | Bm | D | Cm | Eb |
  | F#m | A | Fm | Ab |
  | C#m | E | Bbm | Db |
  | G#m | B | Ebm | Gb |
  | D#m | F# | Abm | Cb |
  | A#m | C# | | |

- Chord symbol above: `^…` before the note, slash, rest, or stack it belongs to (`^Bb7 C4q`, `^G / / / / | ^D / / ^A / /`). A second `^` starts a new symbol at that event. `_` inside that word is a space (`^Any_dom_7`). With no note after it, `^…` is a line chord on an empty staff (`@key=G ^G_Major`). A trailing `^…` or bare `^` after music soft-draws (the mark is ignored until a host follows); a lone empty `^` is rejected
- Tempo for that example: a word `^t=100` (1–500, no leading zero) sets the metronome to that number while the example is showing. The staff prints the number above the next note, slash, rest, or stack. The first mark on the line wins. The next example without `^t=` restores the tempo you had. It does not start the click, and Setup does not save it. Changing the BPM field yourself keeps the number you typed. A `^t=` glued to a note (`C4q^t=100`) stays text above that note
- Text above a symbol: `^text` glued after the duration, or after `]` (`/w^P`, `rw^R`, `[E3h G3h B3h D4h]^C∆7`). Text under a symbol: `_text` (`C4_1`, `/e_R`, `]_3`). Both can sit on one symbol (`]^C∆7_3`, `/q^P_R`). A leading `b`, `#`, `bb`, or `##` prints ♭, ♯, 𝄫, or 𝄪 in either band (`^bVII`, `_bVII`, `_#IV`, `_bbVII`)
- Dynamics under the next note, slash, rest, or stack: `pp` `p` `mp` `mf` `f` `ff` `sfz`. They do not take time. Two in a row, or one with no note after it, is rejected
- Hairpins: `cresc` and `dim` open a wedge from the next note through the note that carries the next dynamic, or through the last note. A hairpin with no note after it is rejected
- Articulations, after the duration dot and before a label: `'` staccato, `>` accent, `-` tenuto, `^` marcato (`C4e'>_1`, `/q>`). A `^` at the end of a note, or a `^` before `_`, is marcato. A `^` followed by text is the above label. A `^` that starts a token is a chord symbol. On a stack, marks typed on any pitch draw once, outside the stem, staccato closest to the note. Marcato points away from the note
- Simile: `%` fills the beats left in the bar (a whole bar, if it starts the bar) with the repeat sign and no slashes. It may follow a chord (`^I∆ / / %`)
- Pitches: `C4`, `C#4`, `Db4`, `Cn4`, doubles `C##4` / `Cx4` / `Ebb4` (letter, optional accidental, octave). The same doubles may be written with 𝄪 and 𝄫. Optional duration after the octave: `w` whole, `h` half, `q` quarter (default), `e` eighth, `s` sixteenth, `n` stemless quarter — e.g. `C4`, `C4h`, `C4e`, `C4s`, `C4n`. `n` is a filled notehead with no stem and lasts one beat, the same time as a quarter. One trailing `.` dots the duration (`C4w.`, `C4q.`, `C4e.`); two dots (`C4q..`) make it 1¾ of the written value. `n.` and `n..` do not parse. A sign is printed when that letter and octave differ from the key, or from an earlier note in the same bar. The next bar starts fresh. `Cn4` still prints a natural. `!` forces the sign even when the bar already showed it (`F#4!`). A note tied across `|` does not repeat the accidental. Degree labels under a note use `_` (`Bb3_1`, `Ab4_b7`)
- Play anything: `/` is a stemless slash on the middle line, one beat, no pitch. Chord charts use it (`^G / / / / | ^D / / ^A / /`)
- Rhythmic slash (pitchless): `/q`, `/e`, `/h`, `/e.`, `/e_R`, `/w^P` — slash notehead on the middle line with stem/beam/dot like a normal note. A whole slash has no stem. `_text` is under it. `^text` is above it
- Rests: `r` / `rq` quarter (default), `rh` half, `rw` whole, `re` eighth, `rs` sixteenth; optional `.` or `..` (`rw.`, `re.`, `rq.`). The dot sits in the third space. The same `_text` and `^text` (`rw^R`, `rw_R`)
- Ties: `~` between two attacks of the same written pitch (`C4q~ C4q`, `/q~/q`, `{/e /e}~{/e /e}`, inside a beam or tuplet). Glued or spaced. The curve joins them; play the first and hold through the second. A tie may cross `|` (`C4q~ | C4q`). A chord ties each pitch it shares. A rest or a different pitch (`C4q~ D4q`, and `C#4` does not match `Db4`) is rejected. A trailing `~` with no next attack hangs as a stub (over a final `|`, or at the end of the line while editing). Every slash matches every slash
- Beams: consecutive `e`/`s` (including dotted `e.`) notes auto-beam within each Setup beat group; a lone short note gets a flag. In **4/4** that group is the quarter, so eighths beam in pairs. In **6/8**, **9/8**, and **12/8** the group is a dotted quarter (three eighths), matching the metronome pulse. An irregular meter such as 5/8 still needs `{…}` when a group should beam, because the beat there is the eighth. `{C4e D4e E4e F4e}` or `{/e /e}` forces one beam group (e/s only; not re-split by meter). A short stack may sit inside a beam (`{C4e [E4e G4e B4e] D4e}`). In a chord, a second keeps the stem-side note in the column and steps the next note to the right: stem up, the lower note stays left; stem down, the upper note stays left. A line that fills whole bars draws a thin barline at the end. A partial bar stays open
- Tuplets: `(3 C4e D4e E4e)`, `(5 /s /s /s /s /s)`, `(3 /q /e)`, `(5:4 …)`. `(N` opens and `)` closes (on the last token or alone). Without `:M`, 3 is in the time of 2; 5–8 of 4; 9–16 of 8; 2 and 4 of 3. The colon form prints the ratio. Inside: notes, slashes, rests, stacks, `{…}` beams; no nested `(`, no `|`. A tuplet with two or more timed units draws with the usual bracket or number and scales by `m/n`. A single note, rest, slash, stack, or one-note beam inside `(N …)` still parses: the shell stays in the text (so Erase can peel), but the staff draws and times it as a plain event. Short notes inside beam only with each other (with braces inside, only the braces beam). The tuplet spans its scaled duration, so auto-beaming after it stays on the beat. A group that is exactly one unbroken beam shows the number only, on the beam side; anything else (quarters and longer, rests, split beams, flags, stacks) gets a bracket, below when every stem points down, otherwise above. Brackets and numbers stay at least ¾ space outside the staff and push chord names and labels out. Digits are SMuFL `tuplet0`–`tuplet9` / `tupletColon`
- Stacked chord: `[C4 E4 G4]` or `[F3 A3 C4 E4]^Dm9`. `^` after `]` is the name above the stack. `_` after `]` is text under it. A pitch inside the stack can carry the same pair (`[E3_3 G3_5 B3_7]^C∆7`). Prefer the same duration on every pitch. If they differ, the stem uses the lowest pitch after the chord is sorted low to high. Nested `[` is rejected. An `e`/`s` stack may sit inside `{…}` beams. Space-separated events left to right; `|` draws a barline
- Time signature is not in the string — it follows Setup meter (`beatsPerBar` / `beatUnit`). **4/4** → common-time **C**; **2/2** → cut-time **₵**; other meters use digits. Beat / compound group size also drives auto-beaming. An exercise may store optional defaults: `clef` (bass), `key`, and recommended `meter`. Line `@bass` / `@treble` / `@key=` still override. In Edit, recommended meter sits beside Bars. On a staff exercise, Write notes holds the exercise clef (one glyph toggle) and key; a recommended meter can offer to update Setup when you open the exercise
- Staff ink (clefs, accidentals, noteheads, slash heads, augmentation dots, flags, rests, time digits / C / ₵) uses Bravura/SMuFL SVG paths in `staff-glyphs.js` (SIL OFL), not a music font. Quarters/halves/eighths/sixteenths get stems; wholes are the whole-notehead glyph only; `n` is the filled quarter head with no stem; beams are SVG lines. Chord labels stay text (`--face-font` / Noto Music for ♯ etc.)

Text examples (not staff) may mark superscript and subscript with the same characters: `C^∆7`, `C^♯`, `H_2O`. A run ends at the next `^` or `_`, at whitespace, or at the end of the line. Plain `C∆7` stays flat; there is no chord heuristic. A word `^t=100` prints as the number and sets the metronome for that example, the same way it does on a staff. Edit → Symbols inserts `^` and `_` with the other chart marks.

`staff-glyphs.js` then `staff.js` load after the exercise scripts and before `picker.js`. `notation.html` (and `es/notation.html`) shows the same parser: the line, then the staff. In Edit, Symbols and the preview sit above the example box in both the one-line and the all-examples views. The line at the caret previews as a staff when it parses; a thin insertion mark tracks the text or pad caret between columns (kept while the line is pending). Moving that mark past the edge of the preview scrolls the staff so the mark stays in view. Tap the preview to place that caret on a column and open Write notes (gaps park after the left token — and after a closing `}` `]` `)` when that is all that sits before the next event — so Erase hits that symbol); drag across columns to select them (same grain as Erase). The staff draws a soft frame around the column(s) Acc / Dur / Erase would affect (including a same-line selection), and with Notes open the example field also highlights the token under the caret. A notation-ish line that fails keeps the last good staff with a red frame and a short why when the parser names the fault. Illegal Beam / Tuplet / Stack wraps and a tie after a rest show a notice instead of doing nothing. After Chord, type the name while Notes stays open. Accidental, duration, and Erase share one current-event under the caret. Pad ←/→ steps drawn note columns — a tuplet opener `(3` is not a column, and beamed notes glued to `)` still count. Multiline paste in one-example view reports how many examples were added. An empty preview coaches one example per line. On a phone that sentence is left off. The staff preview height follows the drawn ink. Staff help (beside Write notes, staff exercises only) opens a short writing guide without closing the draft. Tap an example there to add that line, then the guide closes and the preview draws it. Symbols stays closed until opened. A text exercise shows the chart marks: sharps and flats, chord signs, superscript `^`, subscript `_`, arrows, boxes, a bar, a tie, the repeat sign, and a caption dot. A staff exercise shows the letters. Flat, sharp, natural, duration, and the dot rewrite the note at the caret, or wait for the next letter when the caret is not on a note. Duration and the dot also rewrite a slash or a rest at the caret. Articulation is one menu: staccato, accent, tenuto, or marcato, each drawn on a note. A note keeps one of them. Choosing it again takes the mark off. On a stack the mark is written once. A bare ^ is marcato. A ^ with a name stays the text above the note. Dynamics opens pp, p, mp, mf, f, ff, sfz, cresc, and dim. The word hangs on the note, slash, rest, or stack under the caret, and in front of a beam when the caret is inside one. The same word again removes it. Enharmonic, beside flat, sharp, and natural, flips each selected pitch to its other spelling. A# becomes Bb and Bb becomes A#. A tie flips on both sides. D, G, and A stay. A double sharp or double flat moves once onto the plain spelling. A stack that would then repeat a note is left alone. Up and down on the interval stepper move the note you just wrote, or every pitch in a same-line selection (durations and `^` / `_` marks stay). The interval stays until you pick another, so one note or a selection can move by a third, a fourth, or an octave. There is no octave number on the pad. Add's disclosure always copies the whole example up or down a fourth, a fifth, a step, or a half step, or into a key from the list, and lands on the copy. Write notes has one stepper: the middle shows a short interval (m2, M2, m3, M3, P4, TT, P5, m6, M6, m7, M7, 8ve) and opens that list. It starts at 8ve and keeps whatever you pick. The arrows move the note under the caret, or a selection, by that interval, and an octave keeps the written spelling. The key stays. There is no octave number on the pad. Letter chord symbols move, roman numerals and degree numbers stay, and each copy carries its own `@key=`. Treble starts at 5 and bass at 3. The duration row stays on the pad (whole, half, quarter, eighth, sixteenth) and a dot can be turned on for any of them. A letter writes with that length in the octave shown (`C5`, then `D5`, `C4e`, `C4w.`) with no trailing space, so a tie or a chord mark can stick (`C4~`, `C4^Dm7`). A slash or a rest uses the lit length in one tap (`/q`, `/q.`, `rq`, `rw.`). A MIDI keyboard does the same while Write notes is open, in Chrome or Edge on a computer: one key writes that pitch at the lit length, and keys held together write one stacked chord. The key on the line spells sharps or flats (`F#4` in G, `Db4` in F). A line `@key=` wins over the exercise key. Velocity, the pedal, and the clock are ignored. Write notes starts with the exercise clef (glyph of the clef you get next) and key — not per-line `@bass`. Recommended meter stays beside Bars. Line `@bass` / `@treble` / `@key=` still override when typed. A bar, a tie, a chord mark (`^`), and Beam / Tuplet / Stack sit on the pad. Tuplet is a combo: the face shows the armed number (3, 5, 7, or 4); the disclosure opens a glyph menu to pick N (inside a tuplet the opener rewrites). Beam, Triplet, and Stack light while the caret is inside that shell (same pressed look as an accidental). Tap once to wrap the note, rest, or slash at the caret (or a selection that still parses as that shell — beam needs short notes/slashes, stack pitches only, tuplet no `|`), or to open an empty shell when nothing is there (`{}`, `(3 )`, `[]`). Empty shells still draw (no ink yet). An illegal selection is left alone. The caret stays before the closer so the next letter, slash, or rest joins the group. Tap again while lit: an empty shell is removed; otherwise the caret moves after the closer. Select the whole shell and tap again to unwrap it (inner notes stay). Tap with the caret just after that shell to re-enter instead of opening another group. An empty shell dissolves when Rest, Bar, or Slash cannot live inside it. Tie, Chord, and Bar light when that mark sits just before the caret; a second tap removes it instead of stacking another. A tie after a rest is refused. Beam forces a short duration; letters and slashes inside a beam stay short; a longer duration on a beamed note peels it out (or splits the beam). A rest inside a beam splits the braces around the caret. Duration or the dot inside a stack rewrites every pitch the same way; a long stack under a beam peels out as one piece. A second letter that would duplicate a stack pitch (same letter, accidental, and octave) is written at the next free octave. Bar and simile leave `{}` `[]` `(N…)`. Rest leaves beams and stacks; slash leaves stacks. Chord symbol inside a beam glues `^` onto the note at the caret. Chord inside a stack puts `^` after `]` (the stack name), and a second tap removes that label; a bare `]^` still draws while the name is typed. Stack inside a beam wraps a short pitch. Triplet while inside a beam wraps that whole beam as `(3 {…})`; a selected beam or stack wraps the same way. Beam or Triplet while inside a stack wraps a short stack (`{[E4e G4e]}`) or leaves the stack and opens an empty shell after it. The same shell does not nest in itself; a beam or stack inside a tuplet still wraps. Letters, slash, and rest repeat while held (one undo for the hold). Undo and redo on the pad step through those inserts and the exercise draft (name, bars, recommended meter, key, clef, text/staff). Erase removes the music token before the caret on a staff line, or clears the current example in text; both are undoable. A same-line selection Erase deletes that range, then drops unbalanced `{}` `[]` `(N…)` marks and empty shells so a drag across two groups does not leave a broken line. On a line that draws, Erase after `}` `]` `)` peels the last note inside a beam, stack, or tuplet. Mid-group Erase deletes leftward and keeps the caret there while notes remain on both sides; once nothing is left of the caret inside the group, the caret parks before the closer so the next Erase peels from the end. The last inner note removes its shell (and empty nested parents — so `(3 {})` or `(3 {F#4s})` clears in one tap). A two-note group peels to one note and keeps drawing. Flat / sharp / natural, duration, and the dot rewrite every pitch or rhythm in a selection (octave ↑↓ already did). A long duration on beamed notes peels them out of `{}` the same way a single note does. Dragging over every note in a beam, tuplet, or stack counts as selecting that whole group: Tuplet unwraps a full tuplet or wraps a full beam/stack as `(N …)`; Beam / Stack unwrap when the selection covers that shell. A letter, a slash, or a rest is written after a selection, then the selection clears. A letter on a selected chord still adds that pitch to the chord. Duration, an accidental, and the interval arrows keep the selection and change those notes. One pitch moved by the interval leaves the caret after that note, so the next letter follows it. Several pitches stay selected, and the insertion mark sits after the last one. An empty pad shell still clears in one tap. Erase keeps deleting tokens even when the line will not draw; Undo restores the last good draw. Erase also strips a trailing orphan `|` or `~`, and repeats while held. With Notes open, the Backspace key does the same. The same brackets sit on the text symbols. A new symbol takes a space in front when the previous character would glue the two into one word (`^`, `_`, and `~` stay glued).

## Adding an exercise

Add a script tag after `registry.js` and before `picker.js`. Call `registerExercise` with a new `id`. Put that id in `menuOrder` only when it should seed into the exercise menu. An exercise with `inMenu: false` stays in the code and stays out of the seed list. Do not delete those files to tidy the list. A menu exercise carries `rev`, starting at 1. Bump `rev` when its examples, bars, or label change, and note the date beside that bump. Untouched copies on a device pick up the new text. An edited copy stays.

The rhythms exercise id is `limbs`. Its menu label is Rhythms. Its page is `rhythms.html`. After Restore defaults the menu is All Notes, Scales, All Chords, Chord Tones, Left Hand Rootless Voicings, Essential Progressions, Play/Rest, Rhythmic Devices, Motivic Development, Rhythms, and Free Play. Play/Rest (`playRest`, `play-rest.html`) is two bars of 4/4: a stemless `/` is play anything, and `rq` is a quarter rest. More lists the four-bar whole-note catalog at `more.html#whole-play-rest`: each bar is `/w^P` or `rw^R`, every combination once. The Scales menu exercise is the seven major modes. Harmonic and melodic minor, the melodic-minor modes, pentatonic and blues, and symmetric and bebop stay registered and live in More exercises. Tuplets, Consecutive Eight Notes, Consecutive Triplet-Eight Notes, the two-bar Held rhythm seed (`ties`), Dynamics, Key Signatures (`keySignatures`: every major and minor signature on an empty staff), Sonic Nuances, All Intervals, Approach Notes, and Finger Patterns stay registered and live in More exercises. Tempos (`more.html#tempos`) is a staff exercise of short rhythms, each line marked `^t=` from 60 to 200, so the metronome follows that example and then returns. Four touches (`more.html#four-touches`) is accent, staccato, tenuto, and marcato on rhythm slashes. The same four marks sit on a major scale in quarters (`more.html#major-scale-four-touches`), eighths (`more.html#major-scale-four-touches-eighths`), and triplet eighths (`more.html#major-scale-four-touches-triplets`). More already lists the one-bar Held rhythm catalog at `more.html#held-rhythm`.

When the new id is in `menuOrder`, add a page at the site root, link it from `practice.html`, and add the URL to `sitemap.xml`. Add the Spanish page under `es/`, link it from `es/practice.html`, and list that URL too. `hreflang` on each page points at the other language. That page should link to `./?exercise=` plus the id. On open, the practice screen selects that exercise when it is already on this device, then drops the query from the address bar. A registered exercise that is not on this device offers Add / Edit (or Update), the same way a share hash does; Embed still adds without asking. An id that is not registered is ignored. Restore defaults still seeds only `menuOrder`.

Share sits on the Exercise row in Edit (always visible). It copies a link to the open exercise and shows Link copied in Edit when the clipboard is ready. Embed is the first action under More. It copies an iframe for that same link with `embed=1`, and shows Code copied in Edit. On a phone, Embed, Download, Upload, Ask AI, Clear, and Delete sit in a vertical list under More, and Share, More, Symbols (with staff help when the exercise is staff), and the example view are marks. One example is the default at 640px and under, and also in landscape when the screen is short (phone rotated). A wider screen keeps the words, and from 841px those actions sit beside Share. Edit covers the whole screen. Play does not start while Edit is open, and the reel does not advance. The link is a hash on that page (`https://eization.com/` or `https://eization.com/es/`). A short exercise stays `#s=` plus the examples. A longer one is `#s2=`: the same examples, with each staff line stored as the marks the parser uses and the rest kept as text, then compressed. ## Saved on this device

`eization-desk` keeps tempo, meter, clicks, bars, repeat, swing, count-in, nearby notes, mute, the last exercise, the exercise list, `deletedSeeds`, and `schema`. A shared exercise also stores `shareId` on its row. Two rows may share one `shareId`. It does not store whether the metronome is running.

`schema` is the shape of that object. A missing schema is 0. Schema 1 records `seedRev` and `touched` on each stock row (`seedId` set). `seedRev` is the catalog `rev` last copied onto that row. `touched` means the person edited it. A row with no `seedId` was written here or saved as new. A row saved from a blank Edit sheet also stores `made`. Save as new does not, and neither does an exercise added from a link.

Schema 2 was a one-time reset of the exercise list. Schema 4 is another: the next launch on a device that has not stored schema 4 drops every saved exercise, brings back the stock list, and clears `eization-hello` so the full intro plays. Tempo and meter stay. Schema 4 is stored on that launch, so a later visit does not drop exercises again. Any desk below schema 4 gets that wipe (including schema 2 and 3).

Schema 3 rewrites stored example lines, including edited and custom ones. `]_` right after a stack becomes `]^`, so a chord name that was saved above the stack stays above. `C4_1` and `/e_R` stay. That step did not drop exercises; schema 4’s wipe supersedes it for desks that have not reached 4 yet.

After a wipe (or on a normal launch already at schema 4), stock rows with `touched` false are copied from the current catalog. List order, `shareId`, and `deletedSeeds` stay. A new id in `menuOrder` is appended unless that id was deleted. A grammar change is the next schema step, and it rewrites example lines on every row, including custom ones. That step still does not drop a row that has lines.

The practice screen keeps the display on while that page is in front, so a phone or tablet can sit on the stand while you play. It asks for a screen wake lock as soon as the page is open, again after the first tap, Play, or Next, and again when you come back to it. If the device refuses the lock (older iOS, some Home Screen installs, Low Power Mode), a muted looping video with a silent audio track plays instead. That clip is not the metronome, and the hello tour still must not start the metronome. Switching apps lets the device sleep. Low Power Mode can still turn the screen off.

`eization-hello` is the intro generation, a string. `"1"` means generation 1 has played or been skipped. A missing key plays the full intro. A schema 2 or schema 4 launch clears this key, so the full intro plays on that open. When the tour grows later, bump `HELLO_GEN` in `hello.js` and set `HELLO_RETURN` to the new step range. People already on the previous generation see only that slice, once, on the next launch. Skip stores the new generation. Play the intro again (in Menu → This device) clears only `eization-hello`. Tempo, meter, and exercises stay. The intro plays on the next launch, not on that click.

Install as app sits under the top bar on the practice screen, in English and Spanish. The icon is the point: next time it opens from the home screen or the Dock, with the other music apps, without typing the address. Exercises already stay in the browser through `eization-desk`. The chip does not say that installing saves them. In Chrome and Edge the button opens the browser's install dialog when that browser offers one. On iPhone, iPad, and Safari on Mac it opens the one set of steps for that device. Chrome's step is the Install mark at the top right of the address bar. The other steps draw the marks from that browser: Share, Add to Home Screen, the menu, and the address-bar install icon. Safari on Mac stays a menu path, because File and Add to Dock have no icon. The chip waits out the intro, then another 20 seconds, and can appear on three visits. Not now hides it for that visit; after the third, only the menu item remains. A reload of the same tab does not spend another visit, and an older Not now stored as `1` stays finished. The menu item opens the chip without spending a visit. The metronome does not hide the chip, and the intro caption moves aside if the chip is open. `?embed=1`, `?look=1`, `?smoke=1`, a frame, and an installed window hide it. Safari on Mac keeps a Dock app's saved exercises apart from the browser tab.

## Analytics

The practice screen already loads the Google tag. A few clicks also send an event: tempo start and stop, the exercise you choose, one Next per exercise each visit, edit, share, embed, the intro, language, and Menu. Today, the contribute buttons, and the note at the end of a pass can send `today_exercise`, `contribute_send`, `contribute_correction`, and `pass_share`. Embed in Edit sends `edit_embed` with no exercise body and no hash. Share and Embed on the guide pages can send `guide_share` and `guide_embed`. Those events carry a seed id when the link is `?exercise=`. Otherwise they send no exercise body and no hash. A parameter is a seed id (`custom` when the exercise was made on this device), `model`, `lang`, `link`, or `topic`. The example on screen, a custom title, the email, and payment details stay out. `?smoke=1` sends no events. In the Google Analytics property, register `exercise_id`, `model`, `lang`, `link`, and `topic` as event-scoped custom dimensions.

Another open tab keeps its own screen. Update asks before it replaces an exercise whose lines changed in that other tab. A second Update replaces them. If the other tab removes the exercise on screen, this tab switches to the one now stored. Tempo and meter from the other tab stay there until this tab is reloaded.

Constraints for later sessions are in `.cursor/rules/eization.mdc`.
