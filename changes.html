Hal Crook, How to Improvise

Type one practice focus per line: a chord, a motive, or a comping idea from the chapter you are on. Set Bars to how long that focus lasts. The metronome gives the next focus a turn of its own.

Hal Crook, How to Comp

Type one voicing or one comping rhythm per line. Play it for the bars you set. Next brings a different voicing or rhythm, so the comfortable one does not fill the practice.

Hal Crook, Ready, Aim, Improvise!

Type one soloing target per line, the note or chord you are aiming at. Play toward it for the bars on screen. Each target comes up once.

John A. Elliott, Insights in Jazz

Type one section of a tune per line, the changes you are learning. Set Bars to the length of that section. When every section has come up, you have heard the whole tune in pieces.

Conrad Cork, Harmony with LEGO Bricks

Type one short progression per line, a brick you can move through the keys. Finish the list in one key. Then edit the lines into the next key, or save that key as a new exercise.

Mark Levine, The Jazz Theory Book

Type one progression from the chapter you are in. Scales from the same book belong on scales and pitch sets. Here the metronome counts the bars of the changes.

Alan Kingstone, The Barry Harris Harmonic Method

Type one harmonic move per line, on one degree. Set Bars to the length of that move. Each move comes up once before the list starts again.
