Consecutive Triplet-Eight Notes

A run of consecutive eighth-note triplets that wraps around the bar. For each length from 2 through 7, every starting place on the twelve-slot grid. Rests fill the rest of the bar so it stays 4/4.

Each example comes up once, then the order changes. Every example is one bar of 4/4.

Bring your own examples in Edit, one example per line. How to write on the staff shows how to write a tuplet.
