Tiempo

Pon un ritmo, una polirritmia o una idea métrica en cada línea. En Editar, pon Compases a la duración de ese ritmo. Tocar arranca el clic. Cuando terminan los compases, entra el ritmo siguiente. Cada ejemplo sale una vez. Luego cambia el orden.

Abre Ritmos y márcalo con las manos y los pies. Abre Tocar/Silencio cuando el ejemplo es sonido y silencio. Abre Recursos rítmicos cuando el ejemplo es la duración o la densidad de una frase. Ajustes puede cambiar el compás. El BPM es la velocidad del número de abajo.

Escribe el ritmo que estás practicando. El libro sigue siendo el libro.

Jerry Bergonzi, Inside Improvisation Vol. 4: Melodic Rhythms

Escribe una colocación rítmica de una melodía por línea. Deja quietas las alturas si quieres, y que el ritmo sea el ejemplo. El metrónomo sostiene la rejilla mientras cada colocación sale una vez.

Hal Crook, Beyond Time and Changes

Escribe una idea métrica o una señal de tiempo libre por línea. Para una señal, igual pones Compases para que el clic tenga una duración. Siguiente trae la idea siguiente. El capítulo se queda en el libro. Las imágenes de este libro, el clima o un estallido o una nota larga, están en Juego libre.

Peter Erskine, Time Awareness for All Musicians

Escribe una rejilla de tiempo por línea, algo que puedas marcar. Pon el compás en Ajustes al compás de esa rejilla. Cada rejilla sale una vez antes de que la lista vuelva a empezar.

Ari Hoenig y Johannes Weidenmueller, Intro to Polyrhythms

Escribe una polirritmia por línea. Marca una parte con las manos y la otra con los pies, o toca una parte y deja que el clic sea la otra. Pon Compases a un ciclo completo de esa polirritmia.

Ed Saindon, Exploration in Rhythm

Escribe un ritmo que estás explorando por línea. Tócalo o márcalo durante los compases que pusiste. El ejemplo siguiente es otro ritmo, así el fácil espera su turno.
